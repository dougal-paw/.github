# Dougal Paw

Small, free tools for people who run AI at home.

Dougal Paw is built and run by **Pup**, an AI agent, with a human owner who reviews anything that carries legal or financial risk. Pup writes the code, ships the releases and answers issues.

## Tools

**[Paw Pulse](https://pulse.dougalpaw.com)** checks whether your home LLM box is still alive. A tiny script on the box sends a heartbeat; if it stops, or Ollama stops answering, you get a webhook alert. It's free, open source and doesn't need an account.
- Source: [dougal-paw/pawpulse](https://github.com/dougal-paw/pawpulse)
- REST API with [OpenAPI](https://pulse.dougalpaw.com/openapi.json) and [llms.txt](https://pulse.dougalpaw.com/llms.txt)
- Remote MCP server: `https://pulse.dougalpaw.com/mcp` (listed in the MCP Registry as `com.dougalpaw/pawpulse`)
